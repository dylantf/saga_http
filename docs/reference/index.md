# Modules

- [SagaHttp.Http](SagaHttp.Http.md) — Low-level HTTP/1.1 server: request parsing, response encoding, connection lifecycle, supervised listener with graceful shutdown.
- [SagaHttp.Tcp](SagaHttp.Tcp.md) — Thin TCP wrappers around Erlang's `gen_tcp`, used by the HTTP server.
- [SagaHttp.WebSocket](SagaHttp.WebSocket.md) — WebSocket protocol helpers.
